SUBHRAJIT & SWARNIKA WEDDING WEBSITE

Upload these four files together into the ROOT of one GitHub repository:
1. index.html
2. invitation-cover.jpg
3. letter-background.jpg
4. README.txt

Then enable GitHub Pages:
Repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.

The front page appears first. When the visitor taps "Open the Letter":
- the letter is revealed,
- flower petals begin falling,
- the YouTube embed attempts to autoplay the supplied song from 0:17 and stop at 0:30.
If autoplay is blocked by the browser, tap "Play Song".

Note: YouTube availability, embedding permissions, and autoplay depend on YouTube and the visitor's browser/device.
